## Background

A website for Textile Sewing Services Ltd, a textile manufacturing company. The goal was to give its services and capabilities an online home that works across screen sizes.

## Implementation

The site uses Vue.js 3 and Vue Router for its interface and page navigation, Tailwind CSS for styling, and Vite for the development and production build.

```flow
Vue components -> Route views -> Vite build -> Website
```
